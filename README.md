> Four AIs walk into a stock market. None of them really know what's going to happen — but we're keeping score anyway.

**[🔴 LIVE → markai.garganuj.com](https://markai.garganuj.com)**

## ⚙️ How It Works

1. **Every morning** — all four AIs independently predict NIFTY 50 direction for the day
2. **Market closes** — the actual outcome is recorded
3. **Scores update** — accuracy tracked cumulatively across every session
4. **You can play too** — submit your own prediction, land on the leaderboard, share your call with friends

That's it. No black boxes, no post-hoc explanations. Just a prediction, a result, and a running score.
